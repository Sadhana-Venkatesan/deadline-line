# Deadline Line — Your Deadline, Your Design

An interactive **Countdown Lock Screen Studio** built for the **Handshake AI Skills Studio × Google Gemini** challenge (*“Your Deadline, Your Design: Create a Countdown Lock Screen”*).

![Deadline Line Showcase Cover](exports/handshake-cover-2400x1600.png)

## Why Deadline Line Stands Out
- **Clock-Safe Native Lock Screens Ready Today:** Mathematically calibrated safe zones keep the top 30% clean for the iOS / Android / macOS lock screen clock and widgets, and the bottom 15–18% clear for flashlight, camera, and under-display fingerprint icons.
- **Backward T-Minus Planning:** Turn any target date into 5 chronological `T-minus` milestones (≤ 5 words each) with checkboxes, custom vector milestone icons, and a daily accountability habit.
- **6 Deadline-Matched Design Systems:** *Metro Line* (Swiss transit route map), *Daylight Glass* (frosted botanical bokeh), *Flight Deck* (Braun aerospace telemetry), *Swiss Blueprint* (editorial grid), *Botanical Zen* (calm pine & gold), and *Minimal Ink* (monochrome E-Ink) — each with Midnight/OLED and Daylight/Paper modes.
- **One-Click High-Res Exports + Reminders:** Export Retina Phone (`1290×2796`), Android (`1440×3120`), 4K Desktop (`3840×2160`), and 3:2 Handshake Showcase Cover (`2400×1600`) PNGs, download RFC 5545 daily calendar reminders (`.ics`), copy tailored Google Gemini prompts, share your exact custom lock screen via URL hash, or run **Live Fullscreen Mode**.
- **Zero Dependencies & Privacy-First:** Pure HTML5, CSS3, ES JavaScript, and Canvas 2D — works instantly by double-clicking `index.html` or hosting statically with zero personal data collected.
